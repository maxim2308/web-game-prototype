# 🎮 Web Game Prototype

Прототип веб-игры с системой игроков.

## 🚀 Возможности

- ✅ Система опыта и уровней (XP/Level)
- ✅ Инвентарь с добавлением/удалением предметов
- ✅ Сериализация/десериализация для сохранений
- ✅ Протестировано в E2B sandbox

## 📁 Структура

```
src/
  player.py  - Класс игрока с XP, уровнями и инвентарём
```

## 🧪 Тесты

Запуск тестов:
```bash
python src/player.py
```

Ожидаемый вывод:
```
ALL TESTS PASSED
{'name': 'Hero', 'level': 2, 'xp': 150, 'inventory': {'potion': 1}}
```

## 🔧 Требования

- Python 3.8+
- Никаких внешних зависимостей
